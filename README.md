# Salesforce DevOps — Study & Reference Repo

Personal preparation repo for Salesforce DevOps mid-level roles.
Background: ~4 years DevOps experience, transitioning into the Salesforce ecosystem.

## Goals

- Understand the Salesforce platform architecture and org model
- Learn the Salesforce development lifecycle (SFDX, metadata, deployments)
- Build hands-on experience with CI/CD for Salesforce
- Document key concepts, commands, and gotchas as I learn them

## Structure

```
.
├── notes/                  # Concept notes and study material
│   ├── platform/           # Salesforce platform fundamentals
│   ├── devops/             # CI/CD, pipelines, deployment strategies
│   ├── apex/               # Apex language and development
│   └── tooling/            # SFDX CLI, VS Code extension, etc.
├── scripts/                # Useful shell scripts and automation
├── pipelines/              # Example CI/CD pipeline definitions
│   ├── github-actions/
│   └── jenkins/
└── scratch-org-configs/    # Scratch org definition files for SFDX
```

## Learning Path

1. [ ] Salesforce Platform Basics
2. [ ] Org types: Production, Sandboxes, Scratch Orgs
3. [ ] Salesforce DX (SFDX) and CLI fundamentals
4. [ ] Metadata API and deployment strategies
5. [ ] Version control strategy for Salesforce projects
6. [ ] CI/CD pipeline setup (GitHub Actions)
7. [ ] Apex basics (enough to understand what devs are deploying)
8. [ ] Testing in Salesforce (Apex test classes, code coverage requirements)
9. [ ] Managed packages and AppExchange concepts
10. [ ] Org-wide security model (profiles, permission sets, sharing rules)
